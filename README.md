# Tools Strong

Русскоязычное приложение для локальной обработки видео, аудио и изображений. Чёрно-жёлтый интерфейс, крупные кнопки, без аккаунта, рекламы и загрузки личных файлов на сервер.

Целевое устройство — Samsung Galaxy S24 Ultra с Android 16. `compileSdk/targetSdk = 36`, `minSdk = 29`, устанавливаемый APK — `arm64-v8a`.

## Возможности

- Быстрый режим Telegram/MAX: H.264 MP4, до 720p.
- Сжатие H.264/H.265 по качеству или до размера в МБ; оригинал / 1080p / 720p / 480p. Вертикальные ролики сохраняют ориентацию и пропорции. Для заданного размера проверяется результат и при необходимости повторяется кодирование; при недостижимом лимите приложение показывает ошибку.
- Точная обрезка: оставить участок или вырезать его; обрезка и сжатие за одну операцию. Предпросмотр и миниатюры.
- Поворот, центральное кадрирование и изменение разрешения.
- Видео → MP3/M4A/WAV; конвертация MP3/M4A/WAV.
- Аудио → MP4 с обложкой 16:9 / 9:16 / 1:1, русским названием, автором и опциональной жёлтой аудиоволной.
- PNG/JPG/WEBP → одностраничный PDF и конвертация между изображениями. Прозрачность при сохранении JPEG заменяется белым фоном. Очень большие фотографии уменьшаются перед декодированием, чтобы избежать нехватки памяти.
- Последние 6 результатов; «Открыть», «Поделиться», удаление исходника после подтверждения и при разрешении файлового провайдера.
- Фоновая обработка с уведомлением, прогрессом и отменой; временные файлы удаляются после завершения/ошибки/отмены.

Результаты сохраняются через MediaStore в `Movies`, `Music`, `Pictures` или `Download` → `Tools Strong`. Имена: `Strong_<имя>_<операция>.<формат>`.

## Сборка APK

Нужны JDK 17, Android SDK 36 и Build Tools 36.0.0. Используются Gradle 8.13, AGP 8.13.2, Kotlin/Compose Compiler 2.2.21 и FFmpegKit Maintained Full 8.1.9 (LGPL). H.264/H.265 кодируются через Android MediaCodec; приложение не включает x264/x265.

```bash
./gradlew :app:assembleDebug
```

Локальный результат: `app/build/outputs/apk/debug/app-debug.apk`.

`.github/workflows/build-apk.yml` запускается при push в `main`, pull request и вручную. Он компилирует приложение, запускает JVM-тесты, lint, FFmpeg/ffprobe-проверки, инструментальные тесты на Android 16 и проверяет подпись/выравнивание APK для страниц 16 КБ.

После успешного workflow: artifact **Tools-Strong-APK**, файл **Tools-Strong-1.0.0-debug.apk** и его SHA-256. Отчёты — в **Tools-Strong-validation**.

Подготовка к публикации в RuStore: [описания, данные и порядок подписи release](distribution/rustore/07-перед-публикацией.md). Реальные снимки интерфейса и иконка экспортируются в artifact **Tools-Strong-RuStore-assets**. Загрузка в магазин требует аккаунта издателя и постоянной release-подписи.

Первая версия подписывается автоматически созданным стандартным debug-ключом. Приватного release-keystore нет и он не нужен. Debug-ключ может меняться между сборками; для установки такой новой сборки иногда требуется удалить предыдущую debug-версию. Не храните ключи, пароли или токены в репозитории.

## Проверки

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
python3 scripts/media_smoke_test.py app/build/media-cases.json
./gradlew -PtoolsStrongAbis=x86_64 :app:connectedDebugAndroidTest
```

Тестовый ABI `x86_64` предназначен для эмулятора; итоговый пользовательский APK собирается для ARM64. Проверки на эмуляторе/ПК не заменяют проверку аппаратных кодеков, энергосбережения One UI, HDR и больших файлов на реальном S24 Ultra. Список — [DEVICE_TESTS.md](DEVICE_TESTS.md).
