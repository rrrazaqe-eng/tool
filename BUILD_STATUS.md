# Статус проверки

Проект перенесён из публичного архива, исправлены Gradle-конфигурация, обработка видео и жизненный цикл фонового сервиса. Ветка настроена на API 36 и ARM64.

Добавлены JVM-проверки медиакоманд, FFmpeg/ffprobe-сценарии и Android-инструментальные тесты. Workflow собирает debug APK и публикует его только после прохождения проверок.

Факт успешной сборки и её номер подтверждаются конкретным зелёным запуском GitHub Actions. Этот файл сам по себе не является подтверждением сборки APK или испытаний на Samsung Galaxy S24 Ultra. План аппаратной проверки — DEVICE_TESTS.md.
