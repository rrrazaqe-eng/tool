# Релиз Tools Strong

Целевой пакет: `com.michastrong.toolsstrong`, версия `1.0.0`, код `100`, Android 10+ (API 29), целевой API 36, ARM64. Release-сборка не содержит отладочный суффикс или отладочные инструменты.

```bash
./gradlew :app:lintRelease :app:assembleRelease
```

Без настроенной подписи результат — `app/build/outputs/apk/release/app-release-unsigned.apk`. Этот файл нельзя устанавливать или загружать в магазин как законченный выпуск.

Для подписи используйте постоянное хранилище ключей издателя, размещённое вне каталога публичного репозитория. Нужны переменные окружения:

- `ANDROID_HOME` — каталог Android SDK с Build Tools 36.0.0;
- `TOOLS_STRONG_KEYSTORE` — путь к хранилищу;
- `TOOLS_STRONG_KEY_ALIAS` — псевдоним ключа;
- `TOOLS_STRONG_KEYSTORE_PASSWORD` и `TOOLS_STRONG_KEY_PASSWORD` — пароли.

Передавайте пароли через защищённые настройки среды или секреты CI. Не записывайте значения в репозиторий, команды в переписке или журнал сборки. Создание нового ключа не заменяет сохранение его резервной копии у владельца: будущие обновления должны использовать ту же подпись.

После настройки окружения:

```bash
python3 scripts/sign_release.py
```

Скрипт проверит production-пакет и отсутствие отладочного режима, выполнит выравнивание и подпись, проверит подпись и библиотеки ARM64, затем сохранит `out/Tools-Strong-1.0.0-release.apk` и SHA-256. Он не создаёт ключ и не загружает приложение в RuStore.

## Скриншоты

GitHub Actions получает три неизменённых снимка работающего приложения на Android 16 и экспортирует существующую иконку 512 × 512. Результат — artifact `Tools-Strong-RuStore-assets`. В `capture-manifest.json` указаны версия, устройство, размеры и контрольные суммы. Для съёмки используется тестовый пакет `.debug`; интерфейс взят из того же исходного кода. Это не подтверждение испытаний на физическом Samsung.

## Доступ к магазину

Владелец сначала регистрируется в [RuStore Консоли](https://console.rustore.ru/), создаёт приложение и заполняет контакт поддержки. Для последующей автоматической загрузки нужен отдельно настроенный доступ RuStore API. VK ID или ссылка на профиль сами по себе такого доступа не дают. Секреты RuStore не входят в этот комплект.
