# Сведения о данных и конфиденциальности

Черновик подготовлен по текущему исходному коду и основному манифесту Tools Strong. Это фактическая основа для анкеты RuStore и текста политики. Перед публикацией издатель должен сверить её с окончательным подписанным APK и требованиями консоли. Сведения об издателе и контактах вынесены в отдельный список подготовки.

## Обработка на устройстве

Приложение читает только файлы, которые пользователь выбирает через системный выбор файлов Android. Для обработки могут создаваться временные копии видео, аудио и изображений в кэше приложения. Название и автор, введённые для обложки, используются для оформления выбранного изображения.

Обработка выполняется на устройстве. В основном манифесте нет разрешения на доступ к интернету. В проекте не обнаружены аккаунты, аналитика, рекламные библиотеки, отправка отчётов о сбоях или сервер приложения, получающий файлы и сведения о пользователе. Собственная передача данных разработчику или рекламным партнёрам не предусмотрена.

Выбранный системный поставщик файлов может быть облачным сервисом. Его загрузка файла на устройство и собственные правила обработки данных относятся к этому сервису.

## Что сохраняется локально

| Данные | Назначение | Хранение |
| --- | --- | --- |
| Выбранные видео, аудио и изображения, подготовленные обложки | Выполнение заданной операции | Временные копии в кэше во время обработки |
| Название и автор на обложке | Оформление видео из аудио | Временная обложка и итоговый файл |
| Названия, адреса доступа к файлам, форматы, размеры и время обработки последних шести результатов | История и повторное открытие файлов | Закрытые настройки приложения на устройстве; старые записи вытесняются новыми |
| Состояние операции, имена и адреса исходного и итогового файлов, размеры и прогресс | Отображение обработки и результата | Закрытые настройки приложения на устройстве |
| Готовые видео, аудио, изображения и PDF | Сохранение результата пользователю | Общие папки устройства через системное хранилище Android |

Идентификатор доступа к файлу сам по себе не означает передачу файла в интернет. Содержимое истории и состояния операции не отправляется разработчику.

Временные файлы удаляются обработчиком при штатном завершении, ошибке или отмене. После принудительного завершения процесса часть кэша может сохраниться до очистки средствами Android. Автоматическое резервное копирование данных приложения отключено в основном манифесте.

## Отправка и удаление

Кнопка «Поделиться» по действию пользователя передаёт выбранному стороннему приложению доступ на чтение готового файла. Дальнейшая передача и хранение зависят от выбранного приложения. Tools Strong не отправляет файл в Telegram или MAX автоматически: быстрый режим только подготавливает видео.

Исходный файл сохраняется, пока пользователь отдельно не подтвердит удаление. Удаление зависит от разрешений Android и поставщика файла. Готовые результаты в общих папках не удаляются автоматически вместе с приложением; пользователь может удалить их через файловый менеджер.

Очистка данных или удаление приложения средствами Android удаляет закрытые настройки и кэш приложения. Учётной записи в Tools Strong нет, поэтому отдельной процедуры удаления аккаунта нет.

## Разрешения и назначение

| Возможность Android | Зачем используется |
| --- | --- |
| Уведомления | Показывать прогресс фоновой обработки и кнопку отмены; на Android 13 и новее требуется согласие пользователя |
| Служба переднего плана для обработки медиа | Выполнять выбранную операцию в фоне на Android 15 и новее |
| Служба переднего плана для обработки файлов | Совместимый режим фоновой работы на более ранних поддерживаемых версиях Android |
| Удержание процессора во время операции | Продолжать обработку при выключенном экране; удержание ограничено по времени и освобождается обработчиком |
| Доступ к выбранным файлам | Чтение файлов через системный выбор и сохранение результатов через системное хранилище |

В основном манифесте нет разрешений на камеру, запись с микрофона, геолокацию, контакты и общий доступ ко всей медиатеке. Приложение обрабатывает уже выбранные файлы и не записывает звук с микрофона.

## Основа для анкеты безопасности данных

По текущему коду данные обрабатываются локально, а автоматического сбора и передачи разработчику нет. Если поле анкеты трактует «сбор» как передачу за пределы устройства, оснований заявлять такой сбор не обнаружено. При этом нельзя утверждать, что приложение вообще не использует пользовательские данные: выбранные файлы, текст обложки и локальная история используются для заявленных функций.

Передача по кнопке «Поделиться» инициируется пользователем и направлена в выбранное им приложение. Издателю следует отдельно сверить формулировки соответствующего вопроса RuStore. Заявления об аудите безопасности, шифровании файлов приложением или юридической сертификации в проекте не подтверждены и в черновик не включены.
