# Предлагаемые параметры карточки

Это рекомендации для заполнения анкеты. Итоговые значения определяет издатель по вопросам, которые показывает текущая консоль RuStore.

| Поле | Предлагаемое значение | Основание |
| --- | --- | --- |
| Тип | Приложение | Утилита для работы с файлами |
| Основная категория | Инструменты | Обработка видео, аудио и изображений на устройстве |
| Основной язык | Русский | Интерфейс и описание на русском языке |
| Возрастная маркировка | Предварительно 0+ | В поставляемом интерфейсе нет материалов для взрослых, азартных игр или сцен насилия |
| Реклама | Нет | Рекламные библиотеки и рекламные экраны в проекте не обнаружены |
| Встроенные покупки и подписки | Нет | Платёжная библиотека, платные функции и подписки отсутствуют |
| Учётная запись | Не требуется | Входа и регистрации в приложении нет |
| Общение между пользователями | Нет | Встроенного чата и общедоступной ленты нет |
| Публикация пользовательских файлов на сервер приложения | Нет | Файлы обрабатываются локально; отправку в другое приложение запускает сам пользователь |
| Целевая аудитория | Общая | Приложение не заявлено специально для детей |

Предлагаемая маркировка относится к содержимому самого приложения. Пользователь самостоятельно выбирает свои файлы. Если анкета отдельно спрашивает о создании или редактировании пользовательских материалов, необходимо указать эту возможность; её нельзя приравнивать к отсутствию пользовательского содержимого вообще.

Поддерживаемая конфигурация по проекту: Android 10 и новее, ARM64. Целевая версия Android — 16. Совместимость с конкретными аппаратными кодеками Samsung требует проверки на самом устройстве; черновик карточки не обещает подтверждённую проверку на каждой модели.
